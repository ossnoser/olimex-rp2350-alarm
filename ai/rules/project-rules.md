# Project operating rules

## Work scope

All modifications must be performed exclusively inside the project directory:

```text
/Users/ossnoser/Documents/prj/olimex-rp2350-alarm
```

Files outside this directory must not be modified.

## Rule 1 - Documented and approved task

No project file may be modified without a documented and approved task.

Each task must:

- have a unique sequential identifier using the `TASK-NNNN` format;
- be documented in `docs/tasks/`;
- be listed in `TASKS.md`;
- describe the objective, planned changes, and completion criteria;
- be approved before implementation.

## Rule 2 - English language for project files

All project files must be written in English, including documentation, configuration comments, task documents, AI rules, and future source-code comments unless explicitly approved otherwise.

## Use of the approved task

After approval, the task document becomes the guide for implementing modifications to project files and directories.
