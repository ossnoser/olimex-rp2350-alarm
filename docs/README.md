# Documentation

This directory contains the technical documentation for the project.

## Sections

- `architecture/`: software and firmware architecture.
- `decisions/`: design and architectural decisions.
- `development/`: development environment, toolchain, and framework documentation.
- `hardware/`: Olimex RP2350-PICO2 board documentation and hardware connections.
- `requirements/`: functional and non-functional requirements.
- `tasks/`: sequential documents for approved tasks.
